# affiliate-postback-spec

Open, vendor-neutral reference for server-to-server (S2S) affiliate postbacks in online gambling: event names, payload fields, delivery, retries and signing.

Docs are built with MkDocs and published on Read the Docs. Source lives in `docs/`.
